# Artifact Inventory

This document lists all persistent models, data files, evaluation metrics, and analytics artifacts generated by the system.

## Models
- `artifacts/models/sif_embedding.joblib`: Production SIF Pipeline (Sentence Embeddings + Logistic Regression).
- `artifacts/models/lsr_embedding.joblib`: Production LSR Pipeline (Sentence Embeddings + One-vs-Rest Logistic Regression).
- `artifacts/models/sif_tfidf_baseline.joblib`: (Baseline) TF-IDF SIF model.
- `artifacts/models/lsr_tfidf_baseline.joblib`: (Baseline) TF-IDF LSR model.

## Data
- `data/synthetic_safety_reports_10k.csv`: Raw synthetic ground-truth dataset.
- `data/processed_reports.csv`: Data after NLP preprocessing (lowercasing, stopword removal).
- `data/analytics/enriched_reports.csv`: Full dataset with extracted safety intelligence and SIF/LSR predictions appended.
- `data/demo/demo_reports.json`: 7 canonical deterministic reports for live demonstrations.

## Evaluation
- `artifacts/evaluation/model_comparison.json`: Metrics comparing TF-IDF baselines to Embedding-based production models.
- `artifacts/evaluation/extraction_metrics.json`: Final F1-score performance of the hybrid Precursor Extractor.

## Analytics JSONs (Cached by FastAPI)
- `artifacts/analytics/overall_summary.json`: Top-level KPIs (Total Reports, SIF Count).
- `artifacts/analytics/site_analytics.json`: SIF density and hazard breakdown by Site.
- `artifacts/analytics/activity_analytics.json`: Risk profiling for primary work activities.
- `artifacts/analytics/recurring_patterns.json`: FIM-mined frequent itemsets mapped to Prototype Prioritization Scores.
- `artifacts/analytics/temporal_analytics.json`: Monthly volume and density trends.
- `artifacts/analytics/emerging_trends.json`: Period-over-period comparison highlighting "NEW" and "INCREASING" patterns.

## Demo
- `artifacts/demo/demo_predictions.json`: Deterministic unified pipeline output for the 7 canonical demo reports.
- `artifacts/run_metadata.json`: Environment and model snapshot metadata for reproducibility.
